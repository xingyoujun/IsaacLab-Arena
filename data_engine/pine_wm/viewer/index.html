采集流程与 cuMotion / cuRobo

中心布局 → 可达性及碰撞筛查 → cuMotion 规划 → PhysX 执行并实时记录四视角 → 成功一次即停止 → 用户审核。当前视频为执行实录，没有第二遍轨迹重放；稳定性测试和批量采集未启动。

cuRobo 是 NVIDIA Research 的运动生成库；原生 cuMotion 融合了 Lula 与 cuRobo 的算法。使用 cuMotion 不代表每个算法都在 GPU 上运行。现有 NumPy / SciPy 几何检查在 CPU 上执行；规划与 IK 的 CUDA 覆盖仍需单独验证。RTX 是 GPU 渲染，不能等同于整个流程只执行 CUDA kernel。
