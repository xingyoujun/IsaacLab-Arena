## 审核顺序

先审核 T031 的中心叠塔布局，再审核 T041/T044 抽屉与托盘；之后逐任务处理其他布局。
每次仅启动一个明确授权的预览任务；一次成功后立即停止。用户确认布局、尺寸、视角及随机范围后，才能开放该任务的稳定性测试；稳定性通过后再采集。
当前仅开放预览。容器按逐任务配置在场景实例上缩放，源 USD 不改写；新布局仍待用户视角和任务效果审核。
